## 🚀 How to Use

### Local Development
1. Clone or download this repository
2. Open `index.html` in your web browser
3. No additional setup or dependencies required

### Customization

#### Update Personal Information
In `index.html`, replace the following:
- Email: `rachna@email.com` (line 227)
- Phone: `+1 (555) 123-4567` (line 231)
- Location: `New York, NY` (line 235)
- Social media links in the footer section

#### Modify Projects
Edit the project cards in the `#projects` section (lines 156-225):
```html
<div class="project-card">
    <div class="project-header">
        <h3>Your Project Title</h3>
        <p class="project-category">Category</p>
    </div>
    <p class="project-description">Your project description...</p>
    <div class="project-metrics">
        <span>Your metrics</span>
    </div>
    <div class="project-tech">
        <span class="tech-tag">Technology</span>
    </div>
</div>
```

#### Update Education
Modify the education section (lines 122-144):
```html
<div class="education-item">
    <div class="education-header">
        <h3>Your Degree</h3>
        <span class="year">Your Years</span>
    </div>
    <p class="institution">Your Institution</p>
    <p class="details">Your details...</p>
</div>
```

#### Change Colors
In `styles.css`, modify the color variables (lines 7-14):
```css
:root {
    --primary-color: #0066cc;
    --secondary-color: #00d4ff;
    /* ... other colors ... */
}
```
